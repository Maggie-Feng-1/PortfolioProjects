# PortfolioProjects

Join me as I follow along with [Alex the Analyst's](https://www.youtube.com/@AlexTheAnalyst/featured) Data Analyst Portfolio Project series on YouTube. 

This series utilizes data on Covid-19 found [here](https://ourworldindata.org/covid-deaths). I ran SQL scripts and exported results into an Excel file. Those files were imported into Tableau Public and made into a visual dashboard, view [here](https://public.tableau.com:9443/views/Covid_17955890407770/Covid-19Dashboard?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link).
